Railway & Test Tools

A small collection of browser-based utilities

📐

ETCS Inclinometer Helper V2

Inclinometer tool with visual radar orientation. Pitch with triangle sign selector, tilt, and track slope measurement.
🚂

UIC 7-Digit Check Calculator

Calculate and verify the UIC check digit for 7-digit rolling stock numbers (Výpočet kontrolní UIC číslice). Used in CZ, DE and others.

Experimental

🔢

UIC 12-Digit EVN Calculator

Full 12-digit European Vehicle Number calculator with type code and country code awareness. Supports tractive stock (UIC 438-3), coaches (438-1) and freight wagons (438-2).
📡

Fluke ScopeMeter Viewer

Retrieve and render waveform images from older Fluke ScopeMeters via PostScript output over optical serial cables.
🧭

Orientation Sensor Lab

Live readout of the device orientation & motion APIs — tilt, compass heading, rotation rate and acceleration with a 3D visualizer. Best on a phone.
🌡️

sensor::calc — Temperature Sensors

Bidirectional calculator for RTD (IEC 60751), NTC (β / Steinhart–Hart with datasheet fitter), KTY silicon PTC, thermocouples K–B (ITS-90) and diode junctions. Temperature ↔ Ω / mV.
🔌

Interactive BOM — Sprint Layout

Load a Sprint Layout .lay6 file for an interactive board view with a linked BOM — highlight parts, trace and name electrical nets, measure distances, read off the drill table, mark what is already placed, and export CSV, PNG or SVG. Runs entirely in the browser.
📶

NanoVNA Viewer

Plot Touchstone .s1p / .s2p sweeps from a NanoVNA — return loss, SWR, impedance, phase, |S21|, group delay and a Smith chart, with snapping markers, band overlays, limit lines, zoom/pan and CSV/PNG export. Drag files in, load bundled samples, or drive the VNA over Web Serial with live continuous sweeps and guided calibration.
🚦

ETCS DMI Symbol Catalogue

Every DMI symbol, sound and system status message from ERA_ERTMS_015560 v4.0.0 (CCS TSI Appendix A) — searchable and filterable by colour, with EN/CZ text, cross-linked related symbols, reverse lookup by DMI area, and a quiz mode.
🗼

Antenna Pattern Analyzer

See how antenna type and gain reshape the radiation pattern — isotropic, short and ½λ dipoles, ¼λ monopole, phased pairs, collinear arrays and Yagi-Uda. E- and H-plane polars plus a 3D lobe, with directivity, beamwidth, front/back and side-lobe readouts; plots are absolute dBi, so higher gain visibly pushes the lobe outward.

Privacy

No analytics, no tracking, no cookies, no accounts, no server. Every tool runs entirely in your browser, and the files you open are never uploaded anywhere.

Some tools remember your work — saved readings, placed-component marks, named nets — using your browser's local storage. That stays on your own device and is never transmitted; clearing site data for this domain removes it. Webfonts are served from this site rather than from Google, so no third party sees your visit at all.
